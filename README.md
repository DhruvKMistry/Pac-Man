# Pac-Man (C++)

A C++ recreation of the classic Pac-Man game, built using object-oriented programming and a graphics library to render gameplay.

## Overview

This project implements Pac-Man's core mechanics in C++, using classes to structure game entities and logic, with a graphics library handling rendering and visuals.

## Tech Stack

- **C++** — core game logic, implemented using classes (object-oriented design)
- **Graphics library** — used for rendering the game visuals

## Files

- `PROJECT.CPP` — main source code
- `PROJECT.BAK` — backup file

## Notes

This was an early academic project focused on applying object-oriented programming concepts (classes, encapsulation) to a practical, visual application rather than a purely text-based exercise.
